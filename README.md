# Care500

Care500 is a Nigeria-focused collective medical emergency support concept.

## Website
A responsive static landing page built with plain HTML, CSS and JavaScript. The visual system preserves the Care500 cream, coral and deep-green palette, Bodoni Moda display serif and DM Sans body type.

## Important prototype disclosures
- Contribution checkout is not connected. The site does not accept or process donations.
- Dashboard figures, case summaries and ledger rows are illustrative prototype content, not verified live fund records.
- No beneficiary application, provider portal, payment custody, or fund ledger backend is connected yet.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Before public fundraising
Connect a regulated payment and fund-custody arrangement, verified provider workflows, case eligibility and allocation rules, privacy controls, reconciled public reporting, and legal/regulatory review for Nigeria.
